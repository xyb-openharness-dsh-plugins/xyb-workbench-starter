# HVT 场景推导：十条轴

目的：从一个癌种的疾病事实，推导出**只有这个癌种才成立**的患者高价值场景。不套通用肿瘤清单，不照抄参考项目。

## 使用方法

1. 对十条轴逐条填写"本癌种有什么不一样"。填不出来就写"无显著差异"，不要硬造。
2. 每条轴的答案 × 病程节点（确诊前 / 确诊与分期 / 治疗前 / 治疗中 / 治疗结束 / 复发转移 / 晚期支持 / 长期生存），得到候选场景网格。
3. 每个候选写成三要素句（触发 → 想完成的事 → 产物），进第 3 步打分。

## 十条轴

### A1 病理与分子分型

问：这个癌种的分型会不会改变患者要理解的东西和要问的问题？分型报告里哪些词是患者最容易误解的？

| 癌种 | 本癌种特有的分型事实 | 派生场景 |
| --- | --- | --- |
| 乳腺癌 | ER/PR、HER2、Ki-67；分型决定内分泌/抗 HER2 路径 | 看懂"两阳一阴"、为什么要做 FISH、分型与用药的关系 |
| 卵巢癌 | 上皮性 vs 非上皮性；BRCA1/2、HRD；组织学类型与分级 | 看懂 BRCA/HRD 报告、理解"维持治疗"的前提 |
| 肺癌 | NSCLC vs SCLC 是两条病；EGFR/ALK/ROS1/KRAS、PD-L1 表达 | 分清"病理类型"与"基因变异"、PD-L1 不是靶点 |

常见错误：把"基因检测"和"病理"混成一个页面；把未检出写成全阴性。

### A2 原发器官与局部解剖

问：这个器官被切除/照射/阻塞后，患者身上会发生什么别人不会发生的事？

| 癌种 | 解剖后果 | 派生场景 |
| --- | --- | --- |
| 乳腺癌 | 腋窝处理 → 上肢淋巴回流；乳房切除 → 身体形象 | 四点位臂围、患肢保护、义乳/重建沟通 |
| 卵巢癌 | 盆腔减灭 → 肠功能、腹水、造口可能 | 术后肠功能恢复、腹水与腹胀记录、造口照护 |
| 肺癌 | 肺叶切除 → 肺功能下降；气道 → 咳嗽/气促/咯血 | 术后肺功能与活动耐量、气促分级、咯血处置边界 |

常见错误：把"术后恢复"写成一个通用模板，只换标题。

### A3 分期体系与表述

问：这个癌种用的是哪套分期？患者会在报告上看到哪些字母数字，哪些是不同体系不能混的？

- 乳腺癌：解剖分期 + 生物标志物分期（AJCC 第 8 版引入），TNM 与临床分期要分开。
- 卵巢癌：FIGO 分期（手术分期为主），与 TNM 并行；残余病灶分级（R0/R1/R2）不是分期。
- 肺癌：TNM 第 8/9 版；SCLC 用局限期/广泛期，与 TNM 并行，不能互换。

派生场景：看懂分期原文与版本、知道"分期会随手术病理修正"、残余病灶不等于分期。
常见错误：把不同版本/体系的分期放在同一个字段里比较。

### A4 治疗手段组合

问：这个癌种的主干治疗是什么？哪些是少数情境、不能画成必经步骤？

| 癌种 | 主干 | 少数/特定情境（不能写成常规） |
| --- | --- | --- |
| 乳腺癌 | 手术 + 放疗 + 系统治疗（化疗/内分泌/抗 HER2） | 新辅助、重建、卵巢抑制 |
| 卵巢癌 | 初次减灭或新辅助化疗 + 间歇减灭 + 含铂化疗 + 维持 | 放疗（特定情境）、二次减灭 |
| 肺癌 | 手术/放疗/化疗/靶向/免疫，按分期与分型分叉 | PCI（SCLC）、局部消融 |

派生场景：理解"医生给我排的顺序为什么是这样"、新辅助/辅助的区别、维持治疗要持续多久。
常见错误：把低频手段放进主时间线，让患者以为人人要做。

### A5 复发转移的部位偏好

问：这个癌种最容易转到哪？转到那里会出现什么患者自己能感知的信号？

- 乳腺癌：骨、肝、肺、脑；骨转移 → 骨痛/骨事件。
- 卵巢癌：腹膜、腹腔、肝表面、胸膜；腹水与肠梗阻是主要困扰。
- 肺癌：脑、骨、肝、肾上腺、胸膜；脑转移 → 头痛/癫痫/认知变化。

派生场景：按部位整理影像与症状、区分局部治疗与全身治疗、准备 MDT 问题。
常见错误：只做一个"转移"总标签，不分部位、不分证据层级。

### A6 治疗特有并发症与毒性

问：这个癌种的治疗有哪些患者必须会认、会记、会报的毒性？

- 乳腺癌：内分泌治疗的关节痛/潮热、抗 HER2 的心脏毒性（LVEF）、芳香化酶抑制剂的骨丢失。
- 卵巢癌：铂类的神经毒性与肾毒性、紫杉类的周围神经病变、维持治疗的疲劳。
- 肺癌：免疫相关不良反应（肺炎、甲状腺、结肠炎）、TKI 的皮疹/腹泻、放疗性肺炎/食管炎。

派生场景：把症状与具体治疗关联记录、知道哪些要立刻联系团队、复诊时怎么讲。
常见错误：写成通用"不良反应"清单，不与具体方案关联，不区分"记录"与"处理建议"。

### A7 功能与生活影响

问：治疗结束后，患者在哪些日常动作上会被影响？哪些涉及性、生育、身体形象、工作？

- 乳腺癌：上肢功能、淋巴水肿、身体形象、生育与卵巢功能、性健康。
- 卵巢癌：盆底与肠功能、腹水导致的进食与活动受限、生育（年轻患者）、更年期症状。
- 肺癌：活动耐量、呼吸、咳嗽、声音、吸烟相关污名。

派生场景：用可测量的功能指标（臂围差、前屈角度、6 分钟步行、进食量）替代"感觉如何"。
常见错误：只做情绪量表，不做功能测量；或做测量但不写测量协议。

### A8 随访标志物与影像节奏

问：这个癌种随访看什么？哪些指标不能单独用来判断复发？

- 乳腺癌：CA15-3/CEA 可参考但不单独诊断复发；影像按医嘱。
- 卵巢癌：CA125 是主要标志物，但缓解后单次升高不等于复发；HE4 可选。
- 肺癌：CEA/CYFRA21-1 等仅参考；影像与临床为主。

派生场景：看趋势但不做结论、记录检测方法与单位、标注"复查节奏来自医嘱"。
常见错误：把标志物上升自动写成"进展/复发"；不同方法的结果连成一条线。

### A9 急症与安全边界

问：哪些情况必须立刻就医，产品必须直说"不要在这里等"？

- 乳腺癌：患肢红肿热痛伴发热（感染/淋巴水肿相关）、术后伤口大量渗液。
- 卵巢癌：腹胀急剧加重、停止排气排便（肠梗阻）、发热伴化疗后中性粒细胞下降。
- 肺癌：大咯血、静息气促、新发头痛伴呕吐/抽搐、上腔静脉压迫表现。

派生场景：把"联系团队/急诊"的条件写成可读短语，放在记录入口旁边，不等用户检索。
常见错误：把急症提示写成免责声明；或用 AI 分诊口吻给判断。

### A10 照护者与家庭负担

问：这个癌种的照护者具体在做什么体力/情绪劳动？谁最容易崩？

- 乳腺癌：陪诊、换药、协助上肢训练、形象相关陪伴。
- 卵巢癌：腹水/肠梗阻期的饮食与如厕协助、反复住院陪护。
- 肺癌：吸氧与呼吸观察、夜间咳嗽、突发气促应对。

派生场景：代办者模式、代办者自己的记录空间、"本人不想让家属看到"的边界。
常见错误：把照护者当"另一个患者"，共用同一份可见性设置。

## 从轴到场景：三个必须写进去的字段

| 字段 | 为什么必须 |
| --- | --- |
| 触发 | 决定入口放在哪；没有触发就只能是百科 |
| 产物 | 决定这个场景做完用户拿到什么；没有产物就是日志 |
| 失败恢复 | 决定低精力/断网/资料缺失时还能不能用；没有恢复就是把患者挡在门外 |

## 新癌种的最小工作流

1. 填十条轴，每条不超过三行。
2. 每轴取 1–3 个节点，得到 10–25 个候选。
3. 用三要素句改写，删掉"换成任何癌种都成立"的。
4. 打分，保留 V≥2 且 S≥2 的。
5. 把保留的场景写成 `--terms` JSON 交给 `hvt_scan.py` 做命中统计。
6. 人工逐条判五层，出报告。

参考实现：`scripts/hvt_scan.py` 内置五个癌种的术语包，可直接读来改。
