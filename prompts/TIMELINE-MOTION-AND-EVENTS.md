# 病情一图秀：曲线动画、事件节点与标签的复刻提示词

用途：交给前端开发或设计模型，复用小巢宝截图中“重播趋势动画 → 图上事件节点 → 图下事件标签”的完整体验。以下参数是复刻目标，不能据此宣称当前版本已全部完成。

配套规范：[一图秀数据合同](../docs/16-ONE-CHART-SPEC.md)、[原型工艺指南](../docs/19-PROTOTYPE-CRAFT.md)、[项目填写模板](../templates/ONE-CHART-SPEC.md)。来源：小巢宝卵巢癌工作台原型与事件交互实践。本文以青绿色演示工艺，品牌色、指标与治疗场景需按目标癌种替换；事件语义、日期对齐和交互要求保留。初始化新项目时，本文件会随 `prompts/` 自动复制。

## 可直接使用的完整提示词

请实现一个面向癌症患者与照护者的“病情一图秀”交互原型，重点复刻参考截图中三处彼此关联的细节：右上角“重播趋势动画”按钮、曲线上方的治疗/检查事件节点、图下带明确状态的事件标签。先交付可打开、可操作的 HTML 原型，供用户审核。

### 1. 页面结构与视觉层级

- 页面左上方是“病情一图秀”标题及一句用途说明，右上方并排放置“重播趋势动画”“收藏此入口”。按钮白底、细描边、圆角10–12px，文字使用深灰青色，高度至少44px；按钮组窄屏自动换行，不遮住标题。
- 主区采用左侧220–260px控制栏、右侧 `minmax(0,1fr)` 图表卡。左侧集中指标、近3/6/12月/全期、缩放、事件显隐和候选预览；右侧是事件泳道、指标曲线、图例、事件标签列表。工作台宽度不足960px时控制栏回到主图上方。
- 背景用极浅青灰色，卡片纯白，边框约 `#dae6e4`，圆角16px，内边距20–24px。品牌深青绿约 `#007c80`，主要文字约 `#243c40`。阴影极轻。数字使用 `font-variant-numeric:tabular-nums`。
- 不使用红绿表达病情好坏，不把曲线走势解释成疗效、复发或治疗因果。

### 2. 日期轴与曲线

- 使用同一个日期映射函数定位曲线点、事件节点和时间刻度。示意：`x = left + (date-start)/(end-start)*(width-left-right)`。固定时间窗右端为全局最新记录日期，缩放只调整左边界；不得按数组序号均匀分配日期。
- 最多同时显示4条曲线，每条使用稳定颜色。不同指标各按其自身全期记录范围归一化，筛选时间窗不改变该指标的全期纵向映射；图内和图例明确提示“每条线按自身范围缩放，不代表不同指标数值可比”。原值、单位及全期范围仍可查看。
- 原始测量点始终可见；平滑线仅作点间视觉连接，不生成额外测量值、连续观测或预测。只有同指标、同单位、可比较的方法与实验室记录才连线；单点仅显示点；缺失值不补0。
- 主线宽约3px，圆头圆角；测量点半径4–5.5px，白色描边约2px。日期网格细浅，每屏最多5–7个清晰刻度。末点标签包含原值/单位，靠近右边界时改为向左对齐，必要时交错避让，不得被裁切。

### 3. “重播趋势动画”按钮

- 首次资料加载完成、时间范围/指标选择变化时播放一次；用户点击按钮可重复播放当前视窗。重播只重启图表动画，不重置筛选、翻卡状态、事件显隐、收藏状态、来源详情或页面滚动。
- 用独立 `animationRunId` 控制图层重挂载，或在原生HTML中只更新图表节点/重置动画类。禁止靠整页刷新制造动画。
- 曲线路径使用 `pathLength="1"`；初态 `stroke-dasharray:1; stroke-dashoffset:1`，用 `.85s cubic-bezier(.3,.7,.3,1)` 绘制到0。各条线时长相同，可按序错开80–100ms；不要让点数越多的线耗时越长。
- 数据点用 `.28s` 从 `scale(.4)`/低透明度进入终态，按日期次序每点延迟约45ms。缩放中心设在点自身，避免点飞向SVG原点。点位动画与曲线形成一次完整出现过程。
- 事件节点在独立图层以约 `.28s` 淡入、上移3–5px回位，每个延迟60–75ms；动画不得改变日期定位。
- 快速重复点击不叠加定时器、不重复插入路径、不闪白。重播过程中不修改任何数据。
- `prefers-reduced-motion:reduce` 时关闭位移/旋转/描边动画，并显式设置曲线 `stroke-dasharray:none; stroke-dashoffset:0`，所有点和事件立即显示终态。不能出现关闭动画后曲线消失的情况。

### 4. 曲线上方的事件节点

- 在指标绘图区上方预留独立事件泳道约60–90px，节点X坐标与真实日期严格对齐。事件标记和正文不得覆盖曲线。
- 已发生事件使用青绿色实心点；计划事件使用暖棕色空心点/菱形及“计划”文字；讨论、待核与未知状态有独立标签。不得把所有非已发生事件归为计划，不得因日期已过自动改成已发生。
- 从节点下方画细虚线至泳道底部/指标区上边缘，约1px、`3 5`虚线、透明度 `.35–.5`。引线不穿过指标数据区，避免暗示事件与曲线变化有因果。
- 同日或相近日期事件按屏幕距离分配不同泳道行，保持相同X坐标；密集时增加泳道高度或显示可展开的“+N”，不要水平挪日期或简单取模导致重叠。
- SVG视觉点外提供透明点击区域，使实际点击目标至少24px，触屏优先44px。节点可键盘聚焦，Enter/Space打开详情；保留可见焦点和包含日期、名称、状态的可访问名称。
- 悬停/聚焦快速显示事件日期、标题、状态、来源摘要；点击固定详情，正文原文和附件通过明确入口查看。

### 5. 图下事件标签

- 标签列表从与图上节点完全相同的可见事件集合生成，按日期稳定排序。每项是一整块可点击按钮，格式为“YYYY-MM-DD · 事件标题 + 状态pill”。
- 标签白底、1px浅青灰边框，圆角18–22px，水平内边距12–16px，最小高度44px，间距8px；允许flex换行，长标题正常换行，不挤掉状态文字。
- “已发生”使用浅青绿底/深青绿字；“计划”“沟通/待核”等使用浅底深字并直接写出状态。颜色只是辅助，患者无需记忆颜色含义。
- hover时边框略深、背景略带品牌浅色，过渡约160–180ms。active时图上相应节点和标签共同高亮；有焦点outline；不得靠大幅抖动吸引注意。
- 点击标签和点击其图上节点打开同一事件详情，使用同一个eventId。详情包括事件类别、日期/区间、计划或实际状态、原始描述、关联来源及核对情况。
- 移动鼠标/焦点到标签时，可轻量强调对应图上节点；退出后恢复。关闭详情保留筛选与滚动位置，不自动修改临床事实。
- 隐藏事件轨时节点与标签同步隐藏；说明“事件显示已关闭”，不删除记录。当前时间窗没有事件时解释如何扩大范围。

### 6. 数据与状态边界

- 事件实体至少支持 `id/type/title/startDate/endDate/status/sourceRefs`；保留未知日期、日期精度和来源核对状态。单日点、区间事件使用不同表达，不虚构区间终点。
- 数据层与图表布局层分开：统一实体存事实，图表投影负责筛选、颜色、归一化与泳道分配。不要为了本次HTML布局把前端坐标写回数据库。
- 候选检测值独立预览、不进入正式曲线或统计。患者自述与治疗/检验事实区分，并按用户授权决定是否进入此图。
- 演示资料必须明确标注；指标、事件和治疗场景由目标癌种的患者需求及适用指南确定。例如卵巢癌可使用手术/病理、化疗周期、维持靶向沟通、复发讨论、情境化放疗问题；其它癌种不能直接照搬这份清单。不把讨论记录写成已实施治疗。

### 7. 交付与验收

交付可操作HTML、关键CSS/JS说明和待审核清单。逐项检查：重播不丢状态；日期位置一致；0/1/多点正确；同日多事件不重叠；计划/实际/讨论可辨；图上节点与图下标签同ID联动；缩放后同步筛选；图例/末点标注不裁切；减少动效仍有完整曲线；窄屏仅图表容器内滚动；键盘可以操作所有按钮与事件。审核原型后再同步到正式工作台。


### 2026-10-20 密集事件反馈修正

曲线的位置和高度不能由事件标签行数决定。100+记录/500事件必须仍可在固定趋势区域读图；密集事件在独立六类/项目配置轨道按相邻时间聚合，数字表示原始记录数，保留日期范围与全部成员。原始病程按日期折叠/独立滚动；指标目录、治疗轨分别限制高度。严禁通过隐藏或删除原始事件换取不拥挤。分组趋势卡片详见`docs/24-METRIC-TREND-TAB-DESIGN.md`，指标页与一图秀分类同源。
