# 开发检查点清单：一次性做对（原型与业务页通用）

> 用法：开工前读一遍，每完成一个页面回来逐条勾；**每条都要能一眼看出或一条命令验证**，勾不上就是没做。
> 编号沿用家族文档：`IP` = 交互路径（[28 号](../docs/28-INTERACTION-PATH-DESIGN.md)）、`X` = 交互路径一致性（[15 号](../docs/15-HVT-REVIEW.md)）、`C` = 一图秀（[16 号](../docs/16-ONE-CHART-SPEC.md)）、`MT` = 指标卡与趋势（[24 号](../docs/24-METRIC-TREND-TAB-DESIGN.md)）、`A` = 整页视图（[32 号](../docs/32-FULL-PAGE-VIEW.md)）、`P` = 疾病概要（[36 号](../docs/36-DISEASE-PRIMER.md)）。`Q` 是本清单新增的通用条目。

## 1. 参考基准：小粉宝与小橙宝

家族里两个可直接对照的原型，**照着抄结构与元素体系，不抄病种语义**。

| 基准 | 位置 | 拿什么 | 不拿什么 |
| --- | --- | --- | --- |
| 小粉宝（乳腺癌，成熟基准） | `breast-cancer-workbench/prototypes/v0.4/`（index.html、app.js、style.css、primer-data.js、primer.js） | 首页 hero 与疾病介绍入口、病情整理五 Tab、分类区块眉题、最近值/差值/次数/来源卡、最近报告表、折叠卡、截图墙写法 | 肿瘤分期、治疗线序、疗效应答、肿瘤标志物口径 |
| 小橙宝（AML，结构基准） | `aml-workbench/prototypes/v0.2/index.html`，重点页 `#mind/mind-burden`（心理与家庭/心智负担线） | 一级/二级导航命名与分组、心智负担与生活影响的组织方式、时间线事件泳道、空态与占位文案 | 血液肿瘤的治疗阶段语义、预后与危险度分层 |

### 1.1 家族基线（两套一致，必须遵守）

1. 令牌先于组件：`brand / action / danger / warn / ok / soft` + 圆角 16 + 间距 14，组件只引用令牌。
2. 正文 15px、行高 1.65–1.68，等宽数字（`tabular-nums`），大写档 `body.large` 只放大字号不改布局。
3. 三段外壳：原型声明条（全部模拟、未接入宿主）→ 侧栏 → 顶栏 + 页脚版本行，声明条不可省。
4. 按钮最小高度 42–44px；`:focus-visible` 3px ring、offset 2。
5. 统一类名词汇：`.card / .pill / .notice / .empty / .table-wrap / .section-title`，不自造同义类。
6. 层级只靠字号、降饱和与底纹；阴影只给浮层，不给普通卡片。
7. 口径文案与数字同屏：「仅回顾，不解读」「解读归医生」「不同方法不合并」。
8. 空状态必须给下一步按钮，不只写「暂无数据」。
9. 私密三出口（看板/导出/AI）共用同一过滤函数，并在页内写「N 条中私密 M 条」。
10. AI 输出永远是「候选/预览」，演示态明说未接入。
11. 无障碍：`a.skip` 跳主区、`#main tabindex=-1`、`aria-current`、图表 `role="img"`、折叠用原生 `details`。
12. 断点只用 1180 / 900 / 600 三档。

### 1.2 差异点怎么择优

| 维度 | 取哪套 | 理由 |
| --- | --- | --- |
| 滚动模型 | 小橙宝：视口锁高、`#main` 内滚、顶栏常驻 | 工作台是应用不是长文 |
| 适配单位 | 小橙宝：有 AI 面板时用 container query，按主区宽度断点 | 主区宽度 ≠ 视口宽度 |
| 指标卡 | 小粉宝：真 3D 翻转、固定高度、背面折线 | 翻转不改变栅格高度 |
| 一级导航栏 | 小粉宝：236px、选中态粉底 + 左侧 3px 竖条 | 选中态最清楚 |
| 折叠卡 | 小橙宝：`details.phase-fold` + 打印全展开 | 原生语义、可打印 |
| AI 形态 | 小橙宝：右侧面板 35%、splitter 可调 25–45% | 不遮业务主区 |
| 疾病概要 | 小橙宝：整屏浮层、四段、每段强制来源行 | 与 36 号一致 |

### 1.3 非肿瘤必须替换的表达（照搬即失真）

| 不能搬 | 换成 |
| --- | --- |
| `D+N` 天数、`day_index`、疗程编号折叠 | 缓解期第 N 天 / 发作中第 N 天 + 距上次发作 N 天 + 近 90 天发作次数 |
| 阶段标签（术后/巩固/维持）、化疗按天打勾 | 一次发作 / 一次调药 作为折叠单元 |
| 疗效、预后、fit 评分、MRD 转阴、粒缺阈值自动判定 | 只列医生原文与日期，不判定；阈值一律【待核】 |
| 症状色块/日历 band | 发作—缓解区间带 |
| 指标卡上下降级箭头 | 「较上次」或「近 30 天中位数」，不暗示好坏 |
| 肿瘤标志物趋势话术 | 与疾病活动相关的化验，标注方法/单位/机构可比组 |
| 小时级轨道的事件类型 | 用药 / 就诊 / 检查 / 缓解开始 / 加重 |

急性加重提醒只用患者与医生已确认的行动计划原话，写「若出现 X 联系 Y」，不写「你已进入 Z 期」。

### 1.4 三个「一次性做对」的断言

1. **卡片定高**：`.mcard { height: 194px }` + 双面 `position:absolute; inset:0; overflow:hidden` + 来源行 `margin-top:auto`。断言：任意档案、记录 1 条或 20 条，翻转前后 `getBoundingClientRect().height` 恒 194±1px；同 grid 卡片高度差 ≤1px；翻转不引起相邻卡位移；删掉背面折线后高度不变。
2. **真 3D**：`perspective:1200px` + `preserve-3d` + `rotateY(180deg)` + `backface-visibility:hidden`；单一 `<button aria-pressed>`；JS 只切 state 与 aria，不重建 DOM。断言：翻转中 DOM 节点数不变、焦点仍在同一 button、`aria-pressed` 与背面可见性一一对应、CSS 无 height 过渡、`prefers-reduced-motion` 下 duration 0 仍正确切换。
3. **AI 入口唯一**：顶栏 `top-actions` 固定顺序（资料目录 → 设置 → 大字 → AI → 版本 → ?），右侧面板不遮主滚动，正文只放 `aiBtn('page')` 带上下文入口，`?` 专供疾病概要。断言：任意页组合下顶栏 AI 控件 rect 不变；面板开/关两态 `#main.scrollWidth <= clientWidth`；未接入态输入框 disabled、文案含「未接入/不会发送」、无 fetch。

| --- | --- | --- |

| MT12 | 700/620/窄内容区、大字下无整页横向溢出，二列→一列合理 | 三档宽度各量一次 |

| MT14 | 100+ 记录、500 事件压力数据下曲线仍在固定区域，事件可逐项回查 | 压测一次 |

**3D 翻转最容易"不报错但做错"的五条**：卡片必须**固定高度**（翻转不改变栅格高度，不是展开插入内容）；内层 `transform-style: preserve-3d`；隐藏面 `inert` + `aria-hidden`，不参与 Tab 序；正反面同高，字号变化不塌；键盘可操作（真 `button` 或 `role=button` + Enter/Space），且不嵌套按钮（点数据点不能触发翻卡）。

## 15. 勾选记录怎么写

每条写三样：编号、实测值或证据路径（截图/日志/探针输出）、结论词。结论只用「通过 / 失败 / 跳过（原因）/ 待人工（缺什么）」。

「通过」必须带数字或 `file:line`；没有证据就写「未测」。文档里写了判据、脚本不存在，只能写「待人工」，不能写「通过」。
