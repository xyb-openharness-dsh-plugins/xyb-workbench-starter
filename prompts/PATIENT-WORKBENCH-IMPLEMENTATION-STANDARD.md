# 患者工作台实现标准：白塞病实战补充

与 `FULL-CYCLE-KICKOFF.md` 一起使用。适用于社区患者工作台；按病种和用户已确认范围裁剪，具体医学内容须有来源和临床审核。本标准强化执行与证据要求，不替代现行编号规范、真实闸口或用户明确指令。

## 患者路径与证据

- 用患者关心的问题组织场景，区分真实访谈原话、公开个人叙述、设计假设和合成示例。0 访谈、0 临床审核如实记录；医生工作不可冒充患者需求。
- 对每个一期场景维护「触发→入口→输入→保存或未知→回看/更正→来源→输出及失败恢复」链路，并映射页面、数据与验收。逐项标注空壳、孤儿页、暂缓及未实现；页面数量或术语出现不等于覆盖。医嘱、用药、检查和症状须语义分开，记录医嘱不能创建用药或污染治疗阶段。
- 建立单一证据台账，区分原件已取得、题录、二次来源、未取得和失败；保留 URL、版本、页码及限制。图文冲突原样记录。中国药物适应证核中国官方材料，不能从境外审批推断。未经临床审核的阈值和求助短语保持待核，不输出诊断、治疗选择或自测结论。
- 实读移植样板、成熟基准和用户指定参考的导航、指标卡、布局与交互，记录版本、逐字名称、统计口径和可复现比较；非肿瘤病种不照搬肿瘤分期、线序或 D+N。

## 两组合成档案与一致性

- 两套合成档案覆盖不同病程、信息完整度、发作或主要事件、治疗、跨科资料、指标、未知与私密；遵循病种实际，不虚构访谈、临床结论或未审核阈值。清楚显示合成及刷新、未保存更改的行为。
- 档案的记录、指标、事件、图表和卡片从统一数据源派生。切换时同步隔离记录、已选项、缓存、草稿与私密内容；测试 A→B→A、编辑后切换、空组、缺失信息与跨档案泄露。模拟数据和真实患者事实分离，不能把模拟交互称为持久化或真实服务。

## 指标卡、一图秀和治疗线

- 保留原值、单位、日期精度、方法、机构、参考范围、来源和未知状态；不具备可比性时分组、断线、不算差值。测试未知元数据、同日无序、跨组交错、无效日期、单点和极值，避免错误插值或来源串用。
- 动态卡片实测正反面、鼠标与键盘、焦点恢复、可访问名称、来源、字号和窄屏；图表以全期各指标归一化，单点不连线，治疗/事件与数据分层，治疗条从同一治疗记录源派生。测试时间范围、空状态、末点标签与避让。
- 依据现行 32 号规范实现治疗折叠卡及其适用分块，覆盖空状态、私密过滤、收展与打印恢复；使用实际 PDF 输出核正文。参考设计不得抹掉疾病差异或已有功能。
- 首页提供可见的患者可读疾病简介和概要入口；四段概要与来源状态按现行 36 号执行。标记未取得原件和未审核内容，不把统计量当个人判断。

## 隐私、解析和宿主

- 明确定义导出、摘要、AI 三出口，代码级默认排除私密；确有用户授权的例外逐条选择、显式标记，并验证不同出口各自规则。更正私密属性时保护历史、旧选择和已生成草稿。代记必须落实主体、授权范围与撤权行为，未实现写未实现。
- 云解析前确认服务方、外发内容、用途及已核实的留存删除条款，每次显式授权。文本模拟抽取不是云服务、OCR 或持久化；上传失败、撤回和候选逐条确认均需测试。
- 按 `AGENTS.md` 和 37 号核实 DSH Desktop 实际 App、profile、包和版本；`config.root` 存在不证明服务端消费该配置。检查继承环境变量是否把 CLI profile 误当 Desktop；SSH、Web、构建成功均不等于装机。宿主不可用时遵循现行停止规则，并如实记录未验证。

## 测试与阶段证据

- 用实际浏览器测桌面与窄屏，记录 `innerWidth`、横溢、焦点、返回历史与字体；不把 `--window-size=390` 自动当作真实 390px。README 截图须来自真实渲染，含折叠收展。测试异步读取和打印时等待实际完成，提供正反例；单 HTML 不在探针扫描范围内须显示未检查，SKIP 不算通过。
- 对 X1–X4、C1–C12、MT01–MT15、发布可见性和适用的编号文档逐项留证据、版本、结果与未测范围；独立审查发现的严重缺陷修复留痕。G1 方向确认不自动等于 HVT 通过；G2/G3 与 V1/V2/V3 各自按合同取得真实确认或实测，不能从沉默、截图、check 绿或以前的确认推断。
- 完成后将可复用经验回流到 LESSONS、规范、模板、提示词和适用检查器；区分已落实与待实施，运行 starter 的 check 和 test。未发布版本保持 prerelease。
