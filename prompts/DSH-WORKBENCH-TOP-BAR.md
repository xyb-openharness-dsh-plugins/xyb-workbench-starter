# 工作台顶栏提示词：三段式 + 按钮右置 + 版本号随品牌（可复用）

用途：给 **customFrame** 工作台写宿主主内容区顶部那一条自建 header。它解决三件事——用户找得到「AI 对话」、眼睛知道版本号在哪、顶栏不和业务区抢注意力。
来源：小粉宝乳腺癌工作台 v0.6.1 真机三轮反馈后定稿（2026-10-19）。**不要直接照抄颜色**，颜色按项目品牌换（见 §4 换色规则），结构与层级不要改。

> 前置判断：如果项目用的是 split 形态（`businessSide`/`businessWidth`，宿主自己画分栏），**没有这条自建顶栏**，本提示词不适用；只有 `customFrame=true`（宿主把原生会话节点作为 `conversation` prop 交给插件排版）才用。形态判定见 [docs/20-AGENT-PANE-DESIGN.md](../docs/20-AGENT-PANE-DESIGN.md) §2。

## 1. 一句话结构

**左：品牌 + 版本号；中：一句状态说明（弱化）；右：主操作按钮组，紧贴右边缘。**

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎀 小粉宝  v0.6.1   右侧是 DSH 原生会话：可拖中间分隔边调整宽度（25%–45%）…   [打开 AI 对话] │
└──────────────────────────────────────────────────────────────────────────────┘
   ← 品牌区（谁 + 哪个版本）        ← 说明（为什么这么做）        操作区（现在做什么）→
```

三段各自的职责不许混：

| 区 | 放什么 | 不许放 | 为什么 |
| --- | --- | --- | --- |
| 左 | 项目 logo/名称 + `vX.Y.Z` chip | 操作按钮、二级导航 | 左缘是 macOS 窗口按钮区（`--dsh-frame-leading-clearance`），放按钮会被挤、被误点；品牌+版本是"我在哪、这是哪版"的定位信息 |
| 中 | **一句**状态说明（已连接时说明拖动/收起规则；无会话时说明点哪里开始） | 第二组按钮、教程段落、日志 | 说明文字是辅助，长度一句话；`flex:1` 吃掉中间空白，让右侧按钮自然贴边 |
| 右 | 主操作（`AI 对话` / `打开 AI 对话` / `收起 AI 对话`）+ 必要时一个「×」收起 | 品牌、版本、设置齿轮（除非项目确有设置需求） | 主操作在右缘是视线终点；`margin-left:auto` 一行就能钉住，不依赖父容器宽度计算 |

## 2. 尺寸与间距（可直接抄）

| 元素 | 值 | 说明 |
| --- | --- | --- |
| header 内边距 | `6px 12px` | 竖向 6px 足够薄，不侵占业务区 |
| 起始内边距 | `padding-inline-start: var(--dsh-frame-leading-clearance, 12px)` | **必须**：macOS 收起侧栏后窗口按钮占左上角 |
| 元素间距 | `gap: 10px`；按钮组内 `gap: 6px` | 品牌与版本之间可收紧到 `7px` |
| 换行 | `flex-wrap: wrap` | 窄容器下允许整体换行，**但按钮不许被拆开** |
| 品牌文字 | 12.5px / 700 | 比正文略重，不加字距 |
| 版本 chip | 11px / 500，`border-radius: 999px`，`padding: 1px 8px` | 灰底小胶囊，不做主色 |
| 说明文字 | 11.5px，`flex: 1`，`min-width: 200px` | 颜色比正文淡一档；`min-width` 防被压成竖排 |
| 主按钮 | `padding: 5px 14px`，`border-radius: 999px`，白色文字 | 高度与 header 匹配，不用大号按钮 |
| 按钮组 | `display:flex; align-items:center; gap:6px; flex:0 0 auto; margin-left:auto` | `margin-left:auto` 是"贴右缘"的关键 |

## 3. 颜色：色带必须克制（角色表）

| 角色 | 建议 | 规则 |
| --- | --- | --- |
| header 背景 | 品牌色**极浅**一档，或中性浅灰 | 饱和度压到接近灰；**不要**用品牌主色铺满一条 |
| header 下边框 | 比背景深一档的浅线 | 分隔业务区，不画投影 |
| 品牌文字 | 品牌深色系（非纯黑） | 与业务页品牌一致 |
| 版本 chip | 中性灰底 + 中性灰字 | **不跟随品牌主色**，它是元信息 |
| 说明文字 | 中性灰，比正文淡 | 不能让说明比业务内容更显眼 |
| 主按钮 | 品牌主色降饱和（约 70–80% 饱和） | 全屏只有这一个强色块；hover 可加深一档 |
| 幽灵按钮（收起） | 透明底 + 1px 中性边框 | 不与主按钮争焦点 |

反例（真机上被用户否掉的版本）：`#fbf1f4` 这类明显粉的整条底 + `#d9698a` 饱和主按钮——"色带太抢"，业务区反而退到后面。

## 4. 换色规则（不锁定颜色）

1. 主色取自项目品牌（`assets/brand/BRAND.md` 或品牌令牌），**只用在主按钮与品牌文字**。
2. 背景/边框/chip 一律走中性灰，最多带 3–5% 的品牌色相。
3. 项目若有多档字号（`--tz` 倍率），header 字号也要乘：`calc(12.5px * var(--tz))`；但**版本 chip 与说明文字不放大**（元信息不抢空间），或放大不超过一档。
4. 深浅主题都要给值：深色主题下 header 用比页面背景略亮的中性色，主按钮提亮一档避免糊在一起。

## 5. 结构骨架（抄结构，不抄文案）

```js
// customFrame 组件收到的 props 里，conversation 是宿主交来的原生会话节点
const header = h('header', { style: headerStyle },
  h('span', { style: brandStyle }, `🎀 ${TITLE}`),          // 左：品牌
  h('span', { style: verStyle }, `v${VERSION}`),            // 左：版本（构建注入，不手写）
  h('span', { style: hintStyle }, hintText),                // 中：一句说明，flex:1
  h('div', { style: headerActionsStyle },                   // 右：按钮组，margin-left:auto
    h('button', { onClick: onAgentClick, 'aria-label': `AI 对话：${agentLabel}` }, agentLabel),
    hasConversation && paneOpen && h('button', { onClick: () => setPaneOpen(false), 'aria-label': '收起 AI 对话面板' }, '×'),
  ),
)
```

按钮文案五态（与合同一致，不要自造词）：

| 状态 | 文案 | 点击行为 |
| --- | --- | --- |
| 无会话 | `AI 对话` | `ensureSession({ folder })` 调起原生会话 |
| 连接中 | `正在连接…` | 禁用，防重复创建 |
| 已连接且展开 | `收起 AI 对话` | 只隐藏面板，**不结束会话** |
| 已连接且收起 | `打开 AI 对话` | 重新显示同一会话 |
| 服务缺失 | `AI 对话暂不可用` | 禁用，并说明降级原因 |

## 6. 硬约束（逐条可验）

1. header 必须是根节点的**首个**子元素，且是语义 `<header>`——否则 macOS 窗口按钮避让失效。
2. `padding-inline-start` 用变量 `var(--dsh-frame-leading-clearance, 12px)`，不要写死像素。
3. 版本号必须**由构建注入**（`VERSION`），不在客户端写第二份；业务页若也有版本号，两处同源。
4. 按钮组 `flex: 0 0 auto`，不许被说明文字挤成换行内的碎块；窄容器只允许"整组换到下一行"。
5. 每个图标按钮都要 `aria-label`（尤其「×」）。
6. 说明文字只描述**当前可做的事**与**不会发生的事**（如"收起不会结束会话"），不写营销话术。
7. 顶栏高度固定，不随业务页滚动——它是宿主主内容区的固定条，不参与 iframe 内滚动。

## 7. 验收清单（在真机里看，不看代码）

- [ ] 左缘没有被 macOS 窗口按钮/侧栏按钮压住，品牌与版本完整可见。
- [ ] 版本号在品牌右侧，字号明显小于品牌，颜色是灰的（不会先看到版本号）。
- [ ] 窄窗口下按钮**整组**换行且仍靠右；说明文字被压缩时不竖排、不压住按钮。
- [ ] 主按钮是整条顶栏唯一的强色块；顶栏整体"退后"，业务区仍是视觉主体。
- [ ] 五态文案都出现过（至少：无会话 / 已连接展开 / 已连接收起），点击行为与表一致。
- [ ] 收起后再打开，回到同一会话（输入框里的草稿还在）。
- [ ] 键盘 Tab 能依次到主按钮与「×」，焦点轮廓不被裁切。
