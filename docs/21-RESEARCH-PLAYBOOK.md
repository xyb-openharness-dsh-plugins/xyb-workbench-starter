# 罕见病/新病种调研手册：设计 → 执行 → 输出（可复用流程）

来源：小飞侠 FSHD 工作台首调研（2026-10-18，组织与患者证据部分）。本文是**可复用方法**，不绑定病种；配套模板见 `templates/RESEARCH-PLAYBOOK.md` 引用的项目文档（USER-RESEARCH / SCENARIOS / RESEARCH 证据稿）。

## 0. 适用时机与输入

- 时机：场景排序确认后、SPEC 定稿前；或在已确认 V 清单上做证据补强（如药物管线核验、组织资源核验）。
- 必备输入（缺则先向需求方收集）：
  1. **社群基础资料**：病种简介、患者规模、诊断路径、症状谱、治疗现状、国内资源（患者组织/专家/检测渠道）、国际信息源清单。社群运营方通常已有，直接要。
  2. **关键人物线索**：本病种的知名患者/患者组织发起人（他们公开讲述的经历=最高信噪比的痛点样本）。
  3. **已确认的场景清单**（SCENARIOS 的 V 编号），调研只做证据补强与纠偏，不另起炉灶。

## 1. 调研设计（写进 RESEARCH 文档开头）

| 项 | 要求 |
| --- | --- |
| 调研问题 | ≤5 个，每个能落到"工作台给什么"（例：患者五大诉求是什么？对应 V 几？） |
| 证据边界 | 中国患者优先、国际补充；写明"没有开展患者访谈/临床审核/资格核验" |
| 输出契约 | 1 份 RESEARCH 主文档（结论+表）+ N 份证据稿（逐项来源/URL/局限）+ 修订建议清单 |
| 红线 | 不把规划估算当实测；不把二手招募文案当机制依据；不合并名称近似的组织主体 |

## 2. 执行（四条检索线，按序）

1. **人物线**：搜「病种 + 患者 + 发起人/代表人物」→ 提取时间线（误诊/确诊/转折事件）与原话痛点。人物报道的洞察要转成产品锚点（例：FSHD 案例中"档案化>随访提醒>知识白话化"）。
2. **组织线**：患者组织官网 + 照护者手册（国际组织常有 caregiver brochure，痛点分级最全）+ 跨病种基金会。每家记：名称/类型/地区/服务/局限/URL/证据性质（官网自述≠核验）。
3. **研究线**：近 2 年患者需求问卷/访谈研究（DOI 链接优先）→ 提取诉求清单时**保留原研究"无量化名次"的声明**，不自行排名。
4. **管线线**（无药病种必做）：CT.gov 注册 + 公司公告（SEC/新闻稿）双源；**保留失败与停止开发的管线**，防旧招募页误导；区分「注册节点 vs 临床结果 vs 中国可及性」三层。

工具关系线（可选）：当病种有患者自建技术社区（开源工具/AI 解读）时，单列一节"工具与本病种的关系"，明确与工作台边界是互补不重叠。

## 3. 证据分级与标注

| 级别 | 定义 | 界面处理 |
| --- | --- | --- |
| A | ≥2 独立来源交叉印证 | 直接进场景/验收条 |
| B | 单一可信来源 | 进调研文档，标注来源性质 |
| 未核实 | 仅官网自述/公众号，无交叉 | 界面必须带「未核实」标 + 核对日期 |

所有组织/资源条目固定七字段：`id, name, type, region, service, limit（可及性/局限）, url, evidence（来源性质）`——`limit` 字段强制存在，防"名单变推荐"。

## 4. 输出结构（三件套）

### 4.1 RESEARCH 主文档（项目 docs/RESEARCH-YYYY-MM-DD.md）

```
1. 患者规模（估算=规划情景，明写局限）
2. 药物和技术：常规照护与研究分轨（表：路径/核查结论/患者实际可及性）
3. 患者角度 Top N 诉求 × 工作台可做的事（表：诉求/提供什么/对应 V 编号；保留"无统一名次"声明）
4. 社会组织与代表性机构（表：类别/对象/证据与访问边界）
5. 已补齐的需求与原型差异（SPEC 版本变化、A 条目增补、原型走查入口）
6. 证据缺口与后续验证（列明没验什么）
7. （可选）工具与本病种的关系
```

### 4.2 证据稿（research/ 子目录，一主题一份）

每条证据 = 结论一句话 + 原始 URL + 访问日期 + 局限。主文档只放结论与链接，细节全部下沉。

### 4.3 回写既有文档（调研的落点）

- SPEC：新增 R 条（需求）/A 条（验收），纠正错误表述（例：FSHD 无"ORR/PFS"肿瘤字段）。
- SCENARIOS：优先级调整只写"建议"，变更仍走用户确认（留痕）。
- 原型 resources/trials 数据结构按 §3 七字段更新。

## 5. 质量自查（发布/提交前）

- [ ] 每个结论可回溯到证据稿条目；每个证据条目有 URL + 日期 + 局限。
- [ ] 没有把估算写成实测、把注册节点写成疗效、把官网自述写成核验。
- [ ] 诉求清单保留了原始研究的"无排名"声明。
- [ ] 失败/停止的管线仍在列表里。
- [ ] 与工作台边界一句话说清（工具输出=线索，最终由医生定论）。
