## 2026-10-25 增补（从 CLL 小淋宝 v0.2.0 回收：用户指定的左栏控制版式）

用户原话：「一图秀=左栏（时间范围 chips + 分组指标勾选即时更新 + 显示开关）+ 每条线按自身范围缩放 + 图例带全期区间 + 点选 pin 显示数值/来源」。

这不是新图种，而是把 16 号 R1–R3 落成**固定版式**。判据：

| 要素 | 规范 | 判据 |
| --- | --- | --- |
| 布局 | `.onechart-layout` 两列：左栏 232–268px（sticky）+ 右栏图；<980px 单列、左栏 `position:static`、勾选区不限高 | 窄版无横向滚动 |
| 时间 chips | 近 3/6/12 月 + 全部，`aria-pressed` 单值 | 切换后点数变化、副标题同步 |
| 分组勾选即时更新 | 按系列分组、组内独立滚动（`max-height`）；上限 4 条，选满**回弹并提示**"先去一条再选新的"；描述性指标不可勾 | 只重绘 `#chart-panel`，翻面/焦点不丢 |
| 显示开关 | 治疗节点（独立泳道）+ 点选读数 | 关治疗条后路径 `d` **与所有点 `cy` 都不变**（LESSONS 假面孔 C：先断言有东西再比不变） |
| 每线自身缩放 | 归一化取该指标**全期** min/max（16 号 0.2），不是窗口内 | 切时间窗后线形不跳变 |
| 图例带全期区间 | 每项 = 色点 + 名称 + 全期 min–max + 点数；另有常显句"区间是全部记录的最小–最大，不是正常范围" | DOM 每项含 range 与 n |
| 点选 pin | 点圆点或点图例末点 → 读数条显示 值+单位 / 日期 / 来源（实验室或"报告单原文"）/ 清除 | pin 态圆点描边加粗；读数条 `role="status"` |
| 刻度 | 按**像素间距**抽稀（建议 ≥92 viewBox px），标签用 `YY-MM` | 标签不重叠（本轮踩到：58px 间距仍叠） |
| 空态 | 无任何记录 → 整块空态；窗口内无点 → 空态文案 + 扩大范围/加指标入口；单点不连线 | DOM 无空 `<svg>` |

实现参照：cll-workbench `prototypes/v0.1/app.js` 的 `chartSVG()/lineScale()/pageOnechart()`，
截图 `docs/screenshots/proto-onechart*.png`。
